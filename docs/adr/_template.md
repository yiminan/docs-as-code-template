# 결정 제목

## 상태

제안

결정을 확정하면 `채택`으로 표시합니다. 후속 결정이 기존 결정을 대체하면, 기존 ADR을 `대체됨`으로 표시하고 두 ADR에서 서로 링크합니다.

## 배경

어떤 문제를 해결해야 했고 어떤 제약이 있었는지 적습니다.

## 검토한 대안

고려한 선택지와 각각의 장단점을 적습니다.

## 결정과 이유

선택한 방안과 선택 근거를 적습니다.

## 결과

채택에 따른 효과, 비용, 후속 작업을 적습니다.

## 검증

구현이 결정을 따르는지 확인할 테스트, CI 검사 또는 코드 리뷰 기준을 적습니다. 이미 있는 검사나 테스트가 있다면 링크합니다.
