# 기능 이름

## 상태

초안

프로젝트에 적용된 동작을 설명할 때 `적용 중`으로 표시합니다.

## 목표

어떤 사용자가 무엇을 할 수 있어야 하는지 적습니다.

## 동작과 예외

주요 흐름, 권한, 경계 조건과 실패 시 동작을 적습니다.

## 인수 조건

시나리오마다 사전 상태, 실행할 행동, 관찰할 기대 결과를 적습니다. 각 시나리오를 독립적으로 검증할 수 있게 경계 조건과 실패 상황도 구체적으로 표현합니다.

예약 취소 기능의 인수 조건 예시입니다.

- **사전 상태** 확정 예약의 취소 마감 시각은 15시이고 현재 시각은 14시 59분입니다.
- **행동** 예약한 사용자가 취소를 요청합니다.
- **기대 결과** 예약 상태가 `취소됨`으로 바뀝니다.

## 관련 문서

관련 도메인 용어, 아키텍처 문서, ADR 또는 참조 자료를 링크합니다.
