# Docs-as-code 프로젝트 템플릿

## 새 프로젝트에 적용

`AGENTS.md`, `CLAUDE.md`, `docs/`, `.github/`를 저장소 루트에 배치하고 루트에서 에이전트 세션을 시작합니다.

## 기존 프로젝트에 적용

1. 기존 `AGENTS.md`에 공통 작업 규칙을 합칩니다. Codex에 `AGENTS.override.md`가 우선 적용되면 해당 파일에도 공통 규칙을 반영합니다. 루트 `CLAUDE.md`의 기존 지침을 보존하고 `@AGENTS.md` 가져오기를 한 번만 둡니다.
2. 기존 문서 목차에 [첫 작업 체크리스트와 기능 명세 안내](docs/README.md)를 합치고 필요한 양식을 가져옵니다. 기존 PR 양식에는 [템플릿의 문서 확인 항목](.github/pull_request_template.md)을 합칩니다.
3. 작업 지침, 문서 목차, README, PR 양식에 가져온 상대 링크를 각 문서의 위치를 기준으로 기존 저장소의 파일 경로와 제목 앵커에 맞춥니다.
4. 새 세션에서 각 도구가 실제로 읽는 지침에 공통 규칙이 들어 있는지 확인하고, 통합한 문서의 링크를 검사합니다.

## 첫 작업 계획

[문서 목차의 첫 작업 체크리스트](docs/README.md#첫-작업-계획)로 프로젝트 개요와 첫 기능 명세를 준비합니다.

PR 리뷰에서는 연결한 문서가 변경 내용과 일치하는지 확인합니다. GitHub Actions는 저장소 루트와 `docs/`의 Markdown 파일에서 내부 링크와 앵커를 검사합니다.
