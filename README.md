# Docs-as-code 프로젝트 템플릿

## README URL로 적용

적용할 Git 저장소를 에이전트에서 열고 다음 한 줄을 프롬프트에 붙여넣습니다.

```text
https://github.com/yiminan/docs-as-code-template/blob/main/README.md 의 템플릿을 현재 프로젝트에 적용해줘.
```

### 적용 절차

1. 프롬프트로 받은 README를 읽고, 해당 URL과 같은 저장소의 같은 브랜치, 태그 또는 커밋에서 아래 파일을 가져옵니다. GitHub의 `blob` URL이면 파일의 Raw 보기나 해당 리비전의 저장소를 사용합니다.
   - [AGENTS.md](AGENTS.md)와 [CLAUDE.md](CLAUDE.md)
   - [문서 목차](docs/README.md)와 목차에 연결된 `docs/`의 개요 및 양식 파일
   - [PR 양식](.github/pull_request_template.md)과 [문서 링크 검사 워크플로](.github/workflows/docs-links.yml)
2. `git rev-parse --show-toplevel`로 적용 대상의 루트를 확인하고 기존 에이전트 지침, 문서, PR 양식, CI를 살핍니다. 대상에서 새로 필요한 파일은 템플릿의 상대 경로에 추가하고, 이미 쓰는 파일은 아래 **기존 프로젝트에 적용** 절차에 따라 병합합니다. 템플릿 저장소의 README와 Git 이력은 원본에 둡니다.
3. 같은 요청을 다시 실행해도 추가한 지침이나 링크가 중복되지 않게 합니다. 적용한 파일과 문서 링크를 확인한 뒤 변경한 경로, 실행한 검증 결과, 대상 프로젝트의 첫 작업 계획 위치를 알려줍니다. 변경은 대상의 작업 트리에 남깁니다.

## 새 프로젝트에 적용

위 적용 파일을 저장소 루트에 배치합니다. 저장소 루트에서 새 에이전트 세션을 시작하면 추가한 작업 지침으로 첫 작업을 진행할 수 있습니다.

## 기존 프로젝트에 적용

1. 기존 `AGENTS.md`에 공통 작업 규칙을 합칩니다. Codex에 `AGENTS.override.md`가 우선 적용되면 해당 파일에도 공통 규칙을 반영합니다. 루트 `CLAUDE.md`의 기존 지침을 보존하고 `@AGENTS.md` 가져오기를 한 번만 둡니다.
2. 기존 문서 목차에 [첫 작업 체크리스트와 기능 명세 안내](docs/README.md)를 합치고 필요한 양식을 가져옵니다. 기존 PR 양식에는 [템플릿의 문서 확인 항목](.github/pull_request_template.md)을 합칩니다. 같은 범위를 검사하는 문서 링크 CI가 있으면 재사용하고, 없으면 [링크 검사 워크플로](.github/workflows/docs-links.yml)를 추가하거나 기존 워크플로에 통합합니다.
3. 작업 지침, 문서 목차, README, PR 양식에 가져온 상대 링크를 각 문서의 위치를 기준으로 기존 저장소의 파일 경로와 제목 앵커에 맞춥니다.
4. 각 도구가 읽을 작업 지침 파일에 공통 규칙이 들어 있는지 확인하고, 통합한 문서의 링크를 검사합니다.

## 첫 작업 계획

[문서 목차의 첫 작업 체크리스트](docs/README.md#첫-작업-계획)로 프로젝트 개요와 첫 기능 명세를 준비합니다.

PR 리뷰에서는 연결한 문서가 변경 내용과 일치하는지 확인합니다. GitHub Actions는 저장소 루트와 `docs/`의 Markdown 파일에서 내부 링크와 앵커를 검사합니다.
